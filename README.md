# CyberStudy Lab
Free, static cybersecurity study site. No backend, account, or API key.

## Upload to GitHub Pages (website only)
1. Create a public repository (e.g. `cyberstudy-lab`).
2. **Add file → Upload files**: drag in the *contents* of this folder (keep the `pages`, `css`, `js` folders). Commit.
3. **Settings → Pages → Deploy from a branch**, choose `main` and `/ (root)`, Save.
4. Open the URL shown there after a minute.

All links are relative, so it works under `https://name.github.io/repo/`.

## Notes
- Progress, notes, bookmarks are saved in this browser only (no sync). Export/import in Settings.
- Educational use only. Practise on systems you own or are authorised to test.
- Your earlier single-page version was not modified; keep it as a backup.
